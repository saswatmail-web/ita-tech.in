# ITA corporate website

Responsive one-page website for Independent Technology Advisory.

## Publish
Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root. Keep GitHub Pages set to `main` / `(root)`. Test the GitHub Pages URL before configuring the custom domain.

## Before public launch
Review all service descriptions and founder biography. Replace the contact placeholder once the ITA business email is active. Confirm the final approved logo and contact details. This public repository must not contain credentials, private client information, or confidential business documents.
